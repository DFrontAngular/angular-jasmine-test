Test del servicio

En el test usamos HttpTestingController para interceptar la llamada HTTP.

httpMock.verify() se usa al final de cada test para comprobar que no quedan peticiones pendientes. Es una red de seguridad útil para evitar tests que aparentan pasar dejando trabajo HTTP sin resolver.

Si además el test espera un done() o una emisión que nunca llega porque no hacemos flush() ni error(), el test puede quedarse colgado hasta agotar el timeout.

flush() es un método que simula el paso del tiempo instantáneamente, ejecutando todas las tareas (macrotareas y microtareas) pendientes en la cola de tareas.

¿Qué es useValue?

useValue permite sustituir una dependencia real por una implementación falsa (mock) dentro del sistema de inyección de Angular.

En lugar de usar el TaskService real (que haría llamadas HTTP), proporcionamos un objeto manual con el mismo método: getTasks().

  • provide: indica qué dependencia queremos reemplazar
  • useValue: define el objeto falso que Angular usará en su lugar
  • of(...): crea un Observable síncrono para simular la respuesta
